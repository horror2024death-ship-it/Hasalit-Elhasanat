# Hasalit-Elhasanat
موقع حصالة الحسنات؛ منصة رقمية إسلامية، صُممت كـ صدقة جارية عن أموات المسلمين. الموقع من تطوير المبرمج محمد حمدي؛ ويتميز بواجهة بسيطة، خفيفة، وسريعة الاستخدام. يحتث الزوار على الدعاء، الذكر، واستغلال الوقت في الطاعات؛ مع توفير مزايا تفاعلية، أذكار، وعداد تسبيح ذكي؛ لكسب الأجر والثواب بسهولة.
